## 泰国静态住宅IP两条路：VPS 和代理到底差在哪

VPS 卖的是一台虚拟机加一个固定住宅 IP，代理卖的是 IP 和出口本身。这个差别决定了计费方式和适用场景。

| 对比项 | 泰国 VPS（WePC 这类） | 泰国静态住宅代理 |
| --- | --- | --- |
| 计费单位 | 整台机器按月 | 按 IP 个数按月 |
| 是否含算力 | 含 CPU、内存、硬盘、带宽、流量 | 只给出口，不含算力 |
| 典型月成本 | AUD $24.90 起（约 112–125 元） | $7.90–$7.99/IP |
| 流量 | 1TB 双向，超出限速或另计 | 通常不限流量 |
| 适合场景 | 直播推流、自动化、多开浏览器环境、要独享机器 | 单账号养号、后台登录、广告地区核验、数据采集 |

静态住宅代理（也叫 ISP 代理）的技术定义值得说清楚：IP 由 ISP 分配，服务器托管在数据中心但走的是 ISP 的 ASN，独享、会话长期固定。速度比家庭共享住宅代理快，被识别为机房的概率又比纯 IDC IP 低得多。它和 VPS 里的“原生住宅 IP”在属性上是同一类东西，区别只在于你要不要那台机器。

## 谁该买 VPS，谁买代理就够

判断标准是你要不要那台机器，跟预算关系不大。

**买单台 VPS 的情况**：要跑直播推流，要挂自动化脚本常驻，要在一台机器上开多个浏览器 profile 做环境隔离，或者需要在服务器上自己装软件。这些代理给不了，因为代理只提供出口。

**买代理就够的情况**：单账号或少量账号养号、登录 Shopee 或 Lazada 泰国站后台、做广告投放的地区核验、抓取泰国区页面数据。一个静态住宅 IP 配防检测浏览器就能干活，$7.90/IP/月的成本比开一台 VPS 低得多，也不需要维护系统。论坛里点名要泰国、越南、缅甸静态 IP 的人，相当一部分实际需要的是代理，不是整台服务器。

**两种情况都不适用的情况**：只是要一台泰国机器跑网站或不吃 IP 信誉的机器人。曼谷机房的 VPS 大概 $2–5/月（HostKey、iShosting、No-Ack 这类），便宜得多，但那是 IDC IP，TikTok 的风控体系会把它当低信任段处理，账号限流、直播被掐是常见后果。这类需求买住宅 IP 是浪费钱。

## 常见问题

**电信宽带能直接连泰国线吗？**
上海电信可以。其他地区电信官方建议加 IEPL 中转，不加的话延迟和稳定性都会差一截。移动、联通用户一般不需要。

**WePCMON90 和 WePCYEAR80 能一起用吗？**
不能。一个对应月付和季付，一个对应年付，按你选的计费周期二选一。美国线路的专属折扣码不适用泰国产品。

**IP 被 TikTok 封了能退款吗？**
不能。退款只覆盖 3 天内且流量低于 10GB 的情形。IP 被封可以付费更换，费用约 18 元/次，以工单报价为准。

**能装 Windows 吗？**
默认只提供 Linux，没有 Windows 选项。需要 Windows 环境的话这个产品不合适。

**2 核 512MB 跑得动直播吗？**
推流本身不吃 CPU 和内存，吃的是带宽和回国路由质量。Entry 的 50Mbps 对单路推流够用，瓶颈通常出现在电信不加中转的情况下，而不是配置。要多路并发或同时跑自动化，才需要考虑 Pro 的 500Mbps 和 2TB。
